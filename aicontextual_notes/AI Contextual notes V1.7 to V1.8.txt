1. ACTIVITY FEED - MISSING VENUE INFORMATION
---------------------------------------------
PROBLEM:
Activity feed displayed incomplete session names:
- Showing: "MotoGP Sprint"
- Should show: "Qatar MotoGP Sprint"

ROOT CAUSE:
The activity events are parsed from log lines in motogp_webui.py using regex.
The regex patterns weren't capturing venue information from the updated log format.

FIX:
Updated parse_log_line() function in motogp_webui.py to handle new log format:

BEFORE (log line):
  logger.info(f"📋 Found {len(available)} candidates for {session_type.full_display_name}")

AFTER (log line in motogp_grabber.py):
  logger.info(f"📋 Found {len(available)} candidates for Round {round_num} {venue} - {session_type.full_display_name}")

Updated regex in parse_log_line() to capture round, venue, and session name separately.

  elif '✅ Sort completed:' in message:

3. ACTIVITY FEED - PAGE FLICKERING
----------------------------------
PROBLEM:
Activity page flickered every 3-10 seconds, causing:
- Annoying visual flicker
- Log viewer collapsing repeatedly
- Poor user experience

ROOT CAUSE:
Found in base.html - auto-reload mechanism:
  {% if status.running %}
  setTimeout(() => location.reload(), 3000);
  {% endif %}

This reloaded the ENTIRE page every 3 seconds when any command was running,
destroying SSE connections and UI state.

FIX:
Modified base.html to exclude pages with live SSE streams:

  {% if status.running %}
  const noReloadPages = ['activity', 'logs'];
  if (!noReloadPages.includes(currentTab)) {
      setTimeout(() => location.reload(), 3000);
  }
  {% endif %}

5. PLEX TAGGER - PATH MAPPING FIX
---------------------------------
PROBLEM:
Plex tagger couldn't find files after sorting:
  "File not in Plex yet, waiting 20s... (1/6)"
  "❌ File not found in Plex"

But files WERE visible in Plex UI within 20 seconds.

ROOT CAUSE:
Docker volume mount mismatch:
- MotoGParr container: /mnt/user/data/media → /media
- Plex container: /mnt/user/data/media → /data/media

App searched for: /media/Motorssport/MotoGP/...
Plex stored as:   /data/media/Motorssport/MotoGP/...

Path comparison failed because they didn't match.

FIX:
Added path_mapping to settings.yml:

  plex:
    url: http://192.168.1.241:32400
    token: redacted
    library_id: '16'
    library_name: Motorsport - MotoGP
    path_mapping:
      container: /media          # Path as seen by MotoGParr
      plex: /data/media          # Path as seen by Plex

The translate_path_for_plex() function in utils/config_loader.py uses this
mapping to convert paths when querying Plex API.

================================================================================
ACTIVITY FEED ARCHITECTURE
================================================================================

The activity feed works by:
1. SSE endpoint /activity/stream tails motogp.log file
2. parse_log_line() uses regex to extract structured events from log lines
3. Events sent to browser contain: stage, name, venue, release, score, candidates
4. Frontend JavaScript maintains activity state and renders updates

Stage flow:
searching → found → sending → grabbed → downloading → ready → 
processing → sorting → tagging → plex → complete

Key regex patterns in parse_log_line():
- 🔍 Searching: Round (\d+) (\w+) - (.+)
- 📋 Found (\d+) candidates for Round (\d+) (\w+) - (.+)
- ✅ Sort completed: (\S+) (.+)
- ✅ Successfully processed: (\S+) (.+)
