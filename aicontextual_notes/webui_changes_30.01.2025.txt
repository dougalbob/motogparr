1. WEBUI REFACTORING (v1.3 -> v1.4)
-----------------------------------
Refactored monolithic motogp_webui.py (~800 lines with embedded HTML/CSS/JS) 
into a clean template-based Flask structure:

BEFORE:
- Single file with HTML_TEMPLATE variable using render_template_string()

AFTER - New file structure:
├── motogp_webui.py          # Slim Flask routes only (~400 lines)
├── templates/
│   ├── base.html            # Base template with nav, status, common elements
│   ├── dashboard.html       # Commands tab (quick actions, backfill, overlay)
│   ├── library.html         # Library status tab
│   ├── settings.html        # Settings tab (Grabbing + App Config sub-tabs)
│   └── logs.html            # NEW: Live log viewer with SSE streaming
└── static/
    ├── css/style.css        # All styles (~600 lines)
    └── js/
        ├── app.js           # Shared JavaScript functions
        └── sw.js            # Service worker for PWA (created but not fully used)

3. MOBILE ENHANCEMENTS (v1.4)
-----------------------------
Added responsive design for mobile devices:

a) Bottom Navigation Bar (mobile only)
   - Fixed position at bottom of screen
   - Four tabs: Commands, Library, Settings, Logs
   - Icons with labels
   - Hidden on desktop (uses top tabs instead)

b) Swipe Gestures
   - Swipe left/right to navigate between tabs
   - Implemented in static/js/app.js
   - Uses touch events with gesture detection

c) Pull-to-Refresh
   - Pull down from top to refresh page
   - Visual indicator with arrow/spinner
   - Implemented in static/js/app.js

d) Toast Notifications
   - Non-intrusive popup notifications
   - Replaces old inline "save-notice" elements
   - Types: success, error, warning, info
   - Auto-dismiss after 3 seconds
   - Positioned top-right on desktop, bottom on mobile

e) Collapsible Sections
   - Backfill and Overlay Tools sections collapse
   - Overlay Tools collapsed by default
   - Tap header to expand/collapse
   - Saves screen space on mobile

f) Library Round Details
   - Rounds now expandable/collapsible
   - Tap round header to show/hide sessions
   - Complete rounds have green border

g) Responsive CSS
   - @media queries for screens < 768px and < 380px
   - 2-column quick buttons grid on mobile
   - Stacked form layouts
   - Adjusted font sizes and padding

4. LIVE LOG VIEWER TAB (NEW)
----------------------------
Added new /logs route with real-time log streaming:

Features:
- Server-Sent Events (SSE) streaming from /logs/stream
- Log level filter dropdown (All/Debug+/Info+/Warning+/Error Only)
- Auto-scroll toggle
- Clear display button
- Reconnect button
- Connection status indicator
- Color-coded log lines (error=red, warning=orange, info=blue, success=green)
- Line count and last update timestamp
- Stores all lines client-side for filtering without losing data
- Max 1000 lines retained

Routes added to motogp_webui.py:
- GET /logs - renders logs.html template
- GET /logs/stream - SSE endpoint streaming from /config/logs/motogp.log
- GET /logs/recent - JSON endpoint for recent log lines

5. PWA SUPPORT (PARTIAL)
------------------------
Added Progressive Web App files:

a) Icons created:
   - /assets/icon-192x192.png (orange "MG" logo)
   - /assets/icon-512x512.png
   - Generated using PIL/Pillow

b) Service Worker (/static/js/sw.js):
   - Caches static assets
   - Network-first strategy
   - Bypasses API calls and log streams

c) Manifest updated (/manifest.json):
   - Both 192x192 and 512x512 icons
   - display: standalone
   - theme_color: #ff6600

d) base.html additions:
   - <link rel="manifest">
   - <link rel="apple-touch-icon">
   - Service worker registration script

LIMITATION: PWA installation via Cloudflare Access doesn't work because 
/manifest.json and /sw.js get redirected to OAuth login. Cloudflare Access 
doesn't support path-based bypass on user's plan.

6. APP-LEVEL AUTH (CREATED BUT NOT DEPLOYED)
---------------------------------------------
Created auth.py for optional self-hosted authentication:

Features designed:
- Password hashed with bcrypt
- Session-based authentication (cookies)
- "Remember me" for 30 days
- Password reset via MOTOGPARR_ADMIN_PASSWORD env var
- Password reset via deleting /config/auth.json
- Public paths bypass: /login, /manifest.json, /sw.js, /static/*, /assets/*
- Clean login page matching app theme
- Logout button in header

Files created but NOT in use:
- auth.py (complete implementation)
- Login/logout routes (written but not applied)

User decided not to deploy due to:
- Currently using Cloudflare Access with Google OAuth
- Didn't want to manage open ports
